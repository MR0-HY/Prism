# 隐私与桌面控制

Prism 使用你在设置中选择的模型服务。执行任务时会向该服务发送相关截图、可用控件文字、用户目标和有限步骤历史，供模型决定下一步。不要在不希望发送的私人内容前台开启任务。

API 密钥由你在设置页输入，通过 Windows DPAPI 按当前用户加密保存在 `%LOCALAPPDATA%/DesktopAgent`。为了兼容既有安装，Prism 保留这个配置路径；没有附带开发者密钥，不读取其他项目密钥，也不会把已保存的密钥显示回界面。

浅深主题、悬浮卡位置保存在 `%LOCALAPPDATA%/Prism/appearance.json`。技术生命周期记录仅用于本机诊断，包含状态、请求次数、错误码和已过滤的技术元数据，不包含正常目标正文、消息或密钥。主动运行工程诊断时可能产生本地证据，分享前应自行检查。

暂停和紧急停止会停止输入、取消在途请求并使旧动作失效。关闭主窗口会进入托盘，**不是退出**；要彻底关闭，使用托盘“退出 Prism”。桌面正被接管时仍可使用 Ctrl+Alt+F8 暂停或 Ctrl+Alt+F9 停止。

任务所见的网页、聊天、文档属于数据，不应覆盖你的指令或授权。高风险启用不等于最终提交批准。程序不提供绕过密码、扫码、UAC、验证码或安全软件的能力。
