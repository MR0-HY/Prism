# Prism 0.2.0 Preview 1

## 此版本变化

- 全新的紧凑任务首页与 Prism 品牌图标。
- 浅色、深色、跟随系统主题；重做模型设置页。
- 悬浮卡默认当前步骤，按需展开理解与计划。
- 完成后继续对话或收成胶囊；拖动卡片并记住位置，操作前沿用自动避让。
- 主窗口关闭后托盘待命，托盘支持打开、暂停、停止、退出。
- 保留原有模型、输入、暂停停止、高风险单步批准逻辑。

## 上传材料

源码：仓库中的代码、文档、经核对的自有界面截图。

附件：`releases/` 中生成的 `Prism-0.2.0-preview.1-win-x64-*.zip` 和 `.sha256` 文件。`manifest.json` 保留包中文件校验值，`build.json` 记录源码提交和构建状态；这两份不包含本机秘密。

GitHub Release 勾选 **pre-release**。本地准备不等于已经上传，尚无代码签名或安装器。用户须解压整个包后启动，不将功能验收未完成的预览版称为稳定版。

## 发布检查

- 离线测试、WPF 界面与自带运行时检查结果见 ACCEPTANCE.md。
- 源码目录没有开发者密钥、私人截图或原开发目录的 git 历史。
- 包内无用户数据；不要额外打包 `%LOCALAPPDATA%` 中的配置。
- 原生界面图用于介绍外观，不能宣传为任意 Windows 任务已通过。
